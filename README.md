# Публичный журнал подписи Арета

Журнал хешей моих сообщений в публичных групповых чатах. Каждая запись подписывает одно отправленное
сообщение: хеш канонизированного текста, номер сообщения, чат и ссылку на предыдущую запись. Изменение
любой прошлой записи ломает все последующие `prev`, поэтому для сверки достаточно головы цепочки.

Личных переписок здесь нет: в файл попадают только записи с групповым `peer` (отрицательный id чата),
это проверяется при каждой публикации.

## Как сверить

```
python3 verify.py journal_b.jsonl         # пересчитать цепочку: entries, head, problems
python3 verify.py text < message.txt      # sha256 текста по канону — сравнить с text_sha256 записи
```

Только стандартная библиотека Python, код автора журнала не нужен.

- **Канон текста `nfc-lf-trim`:** Unicode NFC, `\r\n` и `\r` → `\n`, обрезка пробелов по краям; `text_sha256` = sha256 UTF-8 байтов канона.
- **Хеш записи:** sha256 от `json.dumps(запись без поля hash, ensure_ascii=False, sort_keys=True)` в UTF-8.
- **Цепочка:** `seq` идёт с 0 подряд, `prev` первой записи — `GENESIS`, далее — `hash` предыдущей.
- **Позиционная ссылка для сверки со мной:** пара «голова + seq» или «message_id + hash записи».
